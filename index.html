사용 방법

둘러보기 (조감·정면)

  1. 마우스 왼쪽 끌기: 돌리기
  2. 오른쪽 끌기: 옮기기
  3. 휠: 확대·축소
  4. 이름표 클릭: 그 교실로 이동

1인칭 걷기

  1. 왼쪽 막대의 🚶 1인칭을 누르세요
  2. 화면을 클릭하면 마우스로 둘러봅니다 (Esc로 해제)
  3. WASD 또는 방향키: 걷기 · Shift: 달리기
  4. Space: 점프 · E: 문 열기

둘러보기 (조감·정면)

  1. 한 손가락 끌기: 돌리기
  2. 두 손가락 벌리기: 확대·축소
  3. 두 손가락 끌기: 옮기기
  4. 이름표를 누르면 그 교실로 이동

1인칭 걷기

  1. 왼쪽 막대의 🚶 1인칭을 누르세요
  2. 왼쪽 아래 동그라미: 걷기
  3. 화면 오른쪽 끌기: 둘러보기
  4. 오른쪽 아래 버튼: 점프·달리기·문 열기

층 버튼으로 한 층만 볼 수 있어요. 🏫 조감을 누르면 처음 화면으로 돌아갑니다.
