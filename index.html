사용 방법

하늘에서 보기 · 앞에서 보기

  1. 마우스 왼쪽 끌기: 돌리기
  2. 오른쪽 끌기: 옮기기
  3. 휠: 확대·축소
  4. 이름표 클릭: 그 교실로 이동
  5. 이동 모드에서 땅을 클릭하고 여기로 가기: 그곳에서 걷기 시작

1인칭 걷기

  1. 왼쪽 막대의 걷기를 누르세요 (운동장에서 시작)
  2. 화면을 클릭하면 마우스로 둘러봅니다 (Esc로 해제)
  3. WASD 또는 방향키: 걷기 · Shift: 달리기
  4. Space: 점프 · E: 문 열기
  5. 이동 모드에서 바닥을 클릭하면 그곳으로 가요 (마우스 잠금 중에는 가운데 점이 가리키는 곳)

하늘에서 보기 · 앞에서 보기

  1. 한 손가락 끌기: 돌리기
  2. 두 손가락 벌리기: 확대·축소
  3. 두 손가락 끌기: 옮기기
  4. 이름표를 누르면 그 교실로 이동
  5. 이동 모드에서 땅을 톡 누르고 여기로 가기: 그곳에서 걷기 시작

1인칭 걷기

  1. 왼쪽 막대의 걷기를 누르세요 (운동장에서 시작)
  2. 왼쪽 아래 동그라미: 걷기
  3. 화면 오른쪽 끌기: 둘러보기
  4. 오른쪽 아래 버튼: 점프·달리기·문 열기
  5. 이동 모드에서 바닥을 톡 누르면 그곳으로 가요

왼쪽 막대 버튼

  1. 하늘: 학교 전체를 위에서 보기
  2. 앞: 학교 정면 보기
  3. 걷기: 운동장에서 걸어서 둘러보기
  4. 찾기: 교실 이름으로 찾아가기
  5. 드론: 하늘을 날며 건물 안까지 자유롭게 다녀요 (WASD·화살표 이동, Q/E 위아래, 끌어서 둘러보기)
  6. 층보기 (켬/끔): 위층을 잘라 층 안을 위에서 보기
  7. 이름표 (켬/끔): 교실 이름표 보이기/숨기기
  8. 층: 1F~5F 중 한 층만 · 전체=모든 층
  9. 둘러보기/이동: 누르는 방식 바꾸기. 둘러보기(처음)=끌거나 눌러도 둘러보기만, 이동=누른 곳으로 가기 (끌면 둘러보기)
  10. 처음: 처음 화면으로
  11. ◀ / ☰ (왼쪽 위): 막대 접기/펴기 — 접으면 화면을 넓게 써요

휴대폰에서는 버튼을 길게 누르면 설명이 나와요.
